# Homework 05

## Задание
В данной домашней работе решена задача Two Sum двумя способами: brute force и hashmap.

## Решение - часть 1: решение задачи двумя способами и запуск в leetcode
### Код для leetcode brute force:
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []

### Код для leetcode hashmap:
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        index_by_value = {}
        for i, num in enumerate(nums):
            needed = target - num
            if needed in index_by_value:
                return [index_by_value[needed], i]
            index_by_value[num] = i
        return []

### Вывод в части 1
По моему анализу, brute force — O(n2), hashmap - O(n). Однако Runtime на LeetCode у обоих - 0 ms, поэтому визуально разницу оценить не удалось. Brute force перебирает все пары индексов, а hashmap - один проход с O(1) на проверку.

## Решение - часть 2: создание кода с помощью агента
Агент создал два файла two_sum_brute_force.py и two_sum_hashmap.py. С кодом можно ознакомиться в этих же файлах. Для удобства проверки работы агента, в промт был добавлен дополнительный код с теми же входними данными, как на leetcode.

### Промт для агента brute force:
Реши задачу.
Условие: дан массив nums и target. Верни индексы двух чисел, дающих в сумме target. Один элемент дважды нельзя.
Brute force: два вложенных цикла.
Функция, блок if __name__ == "__main__" с проверкой на трёх примерах: [2,7,11,15] с target 9, [3,2,4] с target 6, [3,3] с target 6.

### Ответ агента
Time: O(n²). Memory: O(1).

### Промт для агента hashmap
Теперь реши ту же задачу через HashMap (dict).
Один проход, значение → индекс, ищем target - num.
Функция, блок if __name__ == "__main__" с проверкой на тех же трёх примерах.
Сохрани в новый файл two_sum_hashmap.py, файл two_sum.py не трогай.

### Ответ агента
Time: O(n) в среднем (в худшем случае O(n²) из-за коллизий в dict).
Memory: O(n) — хранение до n пар значение → индекс в seen.
