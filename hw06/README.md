## Решение - часть 1: решение задачи Valid Parentheses
### Код для leetcode
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        parentheses = {')': '(', ']': '[', '}': '{'}
        for symbol in s:
            if symbol in '([{':
                stack.append(symbol)
            else:
                if not stack or stack[-1] != parentheses[symbol]:
                    return False
                stack.pop()
        return not stack

### Вывод в части 1
По моему анализу, память — O(n), время O(n). Accepted на LeetCode, Runtime - 0 ms. Стек подходит, потому что закрывающая скобка всегда относится к последней открытой - принцип LIFO.
