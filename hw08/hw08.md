## (a) Все сдачи студента по фамилии
SELECT u.full_name, a.title, s.created_at, s.status, s.link
FROM users u
JOIN submissions s ON s.student_id = u.id
JOIN assignment  a ON a.id = s.assignment_id
WHERE u.full_name LIKE :surname || '%'
ORDER BY s.created_at;

Что делает: соединяет студентов, их сдачи и задания и выводит все сдачи студентов, чье ФИО начинается с заданной фамилии, с датой, статусом и ссылкой.

## (b) Сколько сдач пришло на каждое задание
SELECT a.id, a.title, COUNT(s.id) AS submissions_count
FROM assignment a
LEFT JOIN submissions s ON s.assignment_id = a.id
GROUP BY a.id, a.title
ORDER BY a.id;

Что делает: для каждого задания считает число пришедших на него сдач через LEFT JOIN и группирует результат по заданию.

## (c) Студенты, не сдавшие ни одной работы
SELECT u.id, u.full_name, u.group_name, u.role, u.telegram
FROM users u
WHERE u.role = 'STUDENT'
  AND NOT EXISTS (
    SELECT 1 FROM submissions s WHERE s.student_id = u.id
  )
ORDER BY u.group_name, u.full_name;

Что делает: выбирает всех пользователей с ролью STUDENT, у которых нет ни одной записи в submissions, и выводит ФИО, группу, роль и телеграм.
